# Getting started

Material Audacity is a Material 3 rewrite of the Audacity 4 shell. This
documentation site describes the rewrite, its features, and how to obtain
builds.

## What changed

- A full Material 3 design system: dynamic color from a single seed, the M3
  type and shape scales, and real Material components.
- A command palette bound to Ctrl+Shift+F that indexes every section, every
  documentation heading, and every setting.
- A regex builder workbench attached to every search and filter field on the
  site and, in the application, throughout its own search surfaces.

## Installing

Windows builds are packaged with Squirrel.Windows and are unsigned. See
the Downloads page for the current asset list and the reason signing is
disabled.
